# Yan-Shuo Pan — Personal Website

Static portfolio website for GitHub Pages.

## Publish

Create a public repository named `YanShuoPan.github.io`, copy this directory to it, and push to the `main` branch. In repository **Settings → Pages**, choose **Deploy from a branch**, `main`, and `/ (root)`.

The site will be available at <https://yanshuopan.github.io>.
